## Source Integrity Statement
The source code in this repository at tag **v1.3.2** is functionally identical to the
code submitted and approved in the Chrome Web Store.

Only non-functional changes (comments and formatting) were applied for readability.
Chrome Web Store packages and signs extensions, therefore binary hashes cannot be
directly compared.
